# Special class scheduling

Admin, Principal and Deputy Principal can schedule an approved special class directly. Section heads can schedule within their assigned sections and academic years. Teachers continue to submit requests for approval.

Open **Special Classes → Schedule a special class** and select the academic year, grade, class, subject and teacher. Teacher choices come from active teacher assignments for that class and subject. Enter a weekend date, start/end time, optional location and reason, then select **Schedule class**.

The existing Saturday/Sunday and overlap checks still apply. A directly scheduled class is approved immediately. Notifications are saved for the assigned teacher, relevant section heads, school leadership, active students in the class and their active linked parents. The creator is excluded from duplicate staff alerts. Notification messages include the location when supplied. Browser push delivery depends on the recipient's browser registration and permission; in-portal notifications remain available.

No database migration is required. The new creation-options endpoint checks the active account and staff record and limits section-head choices to assigned sections and years.

Verification covers Admin/Principal/section-head creation and notification recipients, teacher request approval, conflict/reschedule/cancellation behavior, and scheduling through the Admin and Principal forms in Chrome and WebKit at mobile width. WebKit testing is not a native Safari device test.
